            <h2>About</h2>

            <p>

                I received my Ph.D. studying computer science at the

                <a href="https://www.cs.utah.edu/" target="_blank" rel="noopener">University of Utah School of Computing</a>

                and the <a href="https://www.sci.utah.edu/" target="_blank" rel="noopener">Scientific Computing and Imaging Institute</a>,

                mentored by <a href="https://www.sci.utah.edu/people/valerio.html" target="_blank" rel="noopener">Valerio Pascucci</a>. Currently, I am a postdoctoral researcher at the <a href="https://www.usfca.edu/news/welcoming-full-time-faculty" target="_blank" rel="noopener">University of San Francisco</a> studying geometrically informed machine learning models for physics aware ML supervised by <a href="https://www.usfca.edu/news/welcoming-full-time-faculty" target="_blank" rel="noopener">Mustafa Hajij</a>.

            </p>


            <p>

                My background sits at the intersection of scientific computing, machine learning, and geometry. I recently completed my PhD in computer science, where my work focused on building machine-learning systems that operate directly on scientific and physical data rather than treating ML as a post-processing step.

            </p>


            <p>

                I'm familiar with research and development in various HPC environments like those offered at the <a href="https://www.llnl.gov/" target="_blank" rel="noopener">LLNL</a>, <a href="https://www.ornl.gov/" target="_blank" rel="noopener">ORNL</a>, and the UofU, where I've built production-grade pipelines that couple large-scale simulations with machine learning and visualization. One example is <a href="https://www.ornl.gov/publication/pave-situ-framework-scientific-visualization-and-machine-learning-coupling" target="_blank" rel="noopener">PAVE</a>, an in-situ framework that integrates simulation, visualization, and generative models during runtime, designed specifically to avoid I/O bottlenecks and enable adaptive, learning-driven simulation.

            </p>


            <p>

                Also during my PhD, I introduced <span style="font-style: italic;">topology-native machine learning</span> frameworks that learn directly on simplicial and graph representations derived from Morse–Smale complexes, rather than pixels or raw adjacency alone. My <a href="https://www.proquest.com/openview/8232ec559d1a4ebf139709694c25a9d6/1?pq-origsite=gscholar&amp;cbl=18750&amp;diss=y" target="_blank" rel="noopener">dissertation</a> developed <span style="font-style: italic;">hierarchical topological priors and training</span> schemes that exploit multiscale connectivity (via persistence filtration and hierarchical GNNs) to improve robustness, efficiency, and expressivity, especially under heterophily. Across scientific imaging and graph benchmarks, the thesis demonstrates faster labeling, improved accuracy, and scalable learning by treating topology as a first-class, learnable representation rather than a fixed preprocessing step.

            </p>


            <p>

                More recently, my research has focused on operator-learning and topology-aware models—learning mappings between fields and physical states in a way that's discretization-invariant, geometry-aware, or offering novel and robust workflows for domain experts. Across all of this work, the common thread is building end-to-end systems: defining the right representations, integrating ML with existing computational pipelines, and making these tools usable by domain experts.

            </p>

                <p>

                    Topological analysis reveals meaningful structure in data from a variety of scientific domains. We describe an approach integrating topological priors with graph neural networks for hierarchical feature extraction in scientific images.

                </p>

                <p class="citation">

                    S. Leventhal, A. Gyulassy, V. Pascucci. Modeling hierarchical topological structure in scientific images with graph neural networks.

    <!-- Game of Life Script -->

    <script>

        (function() {

            'use strict';


            var canvas = document.getElementById('gol-canvas');

            var ctx = canvas.getContext('2d');

            var toggleBtn = document.getElementById('gol-toggle');

            var clearBtn = document.getElementById('gol-clear');

            var resetBtn = document.getElementById('gol-reset');

            var hintEl = document.getElementById('gol-hint');


            var cols, rows;

            var grid, nextGrid, ages;

            var cellSize;

            var running = true;

            var animationId;

            var isDrawing = false;

            var paintState = 1;

            var lastCell = { x: -1, y: -1 };


            // Colors

            var colors = {

                alive: '#8b2332',

                trail: ['#e8d4d7', '#f0e4e6', '#f5eded', '#faf9f7'],

                dead: '#faf9f7'

            };


            // Larger cells on small screens so taps land reliably.

            function computeCellSize() {

                var w = window.innerWidth;

                if (w < 420) return 10;

                if (w < 700) return 8;

                return 6;

            }


            function init() {

                cellSize = computeCellSize();

                resizeCanvas();

                createGrid();

                randomize();

                draw();

                if (running) {

                    animate();

                }

            }


            function resizeCanvas() {

                // Use device pixel ratio for crisp rendering.

                var dpr = Math.max(1, window.devicePixelRatio || 1);

                var cssWidth = canvas.offsetWidth;

                var cssHeight = canvas.offsetHeight;

                canvas.width = Math.floor(cssWidth * dpr);

                canvas.height = Math.floor(cssHeight * dpr);

                ctx.setTransform(dpr, 0, 0, dpr, 0, 0);

                cols = Math.floor(cssWidth / cellSize);

                rows = Math.floor(cssHeight / cellSize);

            }


            function createGrid() {

                grid = new Array(cols);

                nextGrid = new Array(cols);

                ages = new Array(cols);

                for (var i = 0; i < cols; i++) {

                    grid[i] = new Array(rows);

                    nextGrid[i] = new Array(rows);

                    ages[i] = new Array(rows);

                    for (var j = 0; j < rows; j++) {

                        grid[i][j] = 0;

                        nextGrid[i][j] = 0;

                        ages[i][j] = 0;

                    }

                }

            }


            function randomize() {

                for (var i = 0; i < cols; i++) {

                    for (var j = 0; j < rows; j++) {

                        grid[i][j] = Math.random() < 0.15 ? 1 : 0;

                        ages[i][j] = grid[i][j] ? 1 : 0;

                    }

                }

                addGlider(Math.floor(cols * 0.1), Math.floor(rows * 0.2));

                addGlider(Math.floor(cols * 0.3), Math.floor(rows * 0.5));

                addGlider(Math.floor(cols * 0.7), Math.floor(rows * 0.3));

            }


            function clearGrid() {

                for (var i = 0; i < cols; i++) {

                    for (var j = 0; j < rows; j++) {

                        grid[i][j] = 0;

                        ages[i][j] = 0;

                    }

                }

                draw();

            }


            function addGlider(x, y) {

                if (x + 2 < cols && y + 2 < rows) {

                    grid[x][y + 1] = 1;

                    grid[x + 1][y + 2] = 1;

                    grid[x + 2][y] = 1;

                    grid[x + 2][y + 1] = 1;

                    grid[x + 2][y + 2] = 1;

                }

            }


            function countNeighbors(x, y) {

                var count = 0;

                for (var i = -1; i <= 1; i++) {

                    for (var j = -1; j <= 1; j++) {

                        if (i === 0 && j === 0) continue;

                        var ni = (x + i + cols) % cols;

                        var nj = (y + j + rows) % rows;

                        count += grid[ni][nj];

                    }

                }

                return count;

            }


            function update() {

                for (var i = 0; i < cols; i++) {

                    for (var j = 0; j < rows; j++) {

                        var neighbors = countNeighbors(i, j);

                        if (grid[i][j] === 1) {

                            nextGrid[i][j] = (neighbors === 2 || neighbors === 3) ? 1 : 0;

                        } else {

                            nextGrid[i][j] = (neighbors === 3) ? 1 : 0;

                        }


                        if (nextGrid[i][j] === 1) {

                            ages[i][j] = Math.min(ages[i][j] + 1, 10);

                        } else if (grid[i][j] === 1 && nextGrid[i][j] === 0) {

                            ages[i][j] = -1;

                        } else if (ages[i][j] < 0) {

                            ages[i][j] = Math.max(ages[i][j] - 1, -4);

                        }

                    }

                }

                var temp = grid;

                grid = nextGrid;

                nextGrid = temp;

            }


            function draw() {

                ctx.fillStyle = colors.dead;

                ctx.fillRect(0, 0, canvas.width, canvas.height);


                for (var i = 0; i < cols; i++) {

                    for (var j = 0; j < rows; j++) {

                        if (grid[i][j] === 1) {

                            ctx.fillStyle = colors.alive;

                            ctx.fillRect(i * cellSize, j * cellSize, cellSize - 1, cellSize - 1);

                        } else if (ages[i][j] < 0) {

                            var trailIndex = Math.min(Math.abs(ages[i][j]) - 1, colors.trail.length - 1);

                            ctx.fillStyle = colors.trail[trailIndex];

                            ctx.fillRect(i * cellSize, j * cellSize, cellSize - 1, cellSize - 1);

                        }

                    }

                }

            }


            function animate() {

                update();

                draw();

                if (running) {

                    animationId = setTimeout(function() {

                        requestAnimationFrame(animate);

                    }, 100);

                }

            }


            function setRunning(next) {

                running = next;

                toggleBtn.textContent = running ? 'Pause' : 'Play';

                toggleBtn.classList.toggle('primary', !running);

                toggleBtn.setAttribute('aria-pressed', String(!running));


                if (running) {

                    canvas.classList.remove('interactive');

                    hintEl.classList.remove('visible');

                    animate();

                } else {

                    canvas.classList.add('interactive');

                    hintEl.classList.add('visible');

                    clearTimeout(animationId);

                }

            }


            function toggle() {

                setRunning(!running);

            }


            function reset() {

                clearTimeout(animationId);

                createGrid();

                randomize();

                draw();

                if (running) {

                    animate();

                } else {

                    // Stay paused but show fresh random state for editing.

                    setRunning(false);

                }

            }


            function clearAction() {

                if (running) {

                    setRunning(false);

                }

                clearGrid();

            }


            function getCellFromEvent(e) {

                var rect = canvas.getBoundingClientRect();

                var clientX, clientY;

                if (e.touches && e.touches.length > 0) {

                    clientX = e.touches[0].clientX;

                    clientY = e.touches[0].clientY;

                } else if (e.changedTouches && e.changedTouches.length > 0) {

                    clientX = e.changedTouches[0].clientX;

                    clientY = e.changedTouches[0].clientY;

                } else {

                    clientX = e.clientX;

                    clientY = e.clientY;

                }


                // rect is in CSS pixels; our transform also works in CSS pixels.

                var x = Math.floor((clientX - rect.left) / cellSize);

                var y = Math.floor((clientY - rect.top) / cellSize);


                return { x: x, y: y };

            }


            function setCell(x, y, state) {

                if (x >= 0 && x < cols && y >= 0 && y < rows) {

                    grid[x][y] = state;

                    ages[x][y] = state ? 1 : 0;

                    draw();

                }

            }


            function handleStart(e) {

                // Auto-pause on first interaction so users don't have to hunt for the Pause button.

                if (running) {

                    setRunning(false);

                }

                e.preventDefault();

                isDrawing = true;

                var cell = getCellFromEvent(e);

                lastCell = cell;

                // Toggle the first cell and lock in the paint state for dragging.

                if (cell.x >= 0 && cell.x < cols && cell.y >= 0 && cell.y < rows) {

                    var newState = grid[cell.x][cell.y] === 1 ? 0 : 1;

                    setCell(cell.x, cell.y, newState);

                    paintState = newState;

                }

            }


            function handleMove(e) {

                if (!isDrawing) return;

                e.preventDefault();

                var cell = getCellFromEvent(e);


                if (cell.x !== lastCell.x || cell.y !== lastCell.y) {

                    setCell(cell.x, cell.y, paintState);

                    lastCell = cell;

                }

            }


            function handleEnd() {

                isDrawing = false;

                lastCell = { x: -1, y: -1 };

            }


            toggleBtn.addEventListener('click', toggle);

            clearBtn.addEventListener('click', clearAction);

            resetBtn.addEventListener('click', reset);


            // Pointer events cover mouse, pen, and touch uniformly.

            if (window.PointerEvent) {

                canvas.addEventListener('pointerdown', function(e) {

                    canvas.setPointerCapture(e.pointerId);

                    handleStart(e);

                });

                canvas.addEventListener('pointermove', handleMove);

                canvas.addEventListener('pointerup', handleEnd);

                canvas.addEventListener('pointercancel', handleEnd);

                canvas.addEventListener('pointerleave', handleEnd);

            } else {

                // Fallback for older browsers.

                canvas.addEventListener('mousedown', handleStart);

                canvas.addEventListener('mousemove', handleMove);

                canvas.addEventListener('mouseup', handleEnd);

                canvas.addEventListener('mouseleave', handleEnd);

                canvas.addEventListener('touchstart', handleStart, { passive: false });

                canvas.addEventListener('touchmove', handleMove, { passive: false });

                canvas.addEventListener('touchend', handleEnd);

                canvas.addEventListener('touchcancel', handleEnd);

            }


            // Debounced resize: recompute cell size and grid to keep things readable on rotate.

            var resizeTimer;

            window.addEventListener('resize', function() {

                clearTimeout(resizeTimer);

                resizeTimer = setTimeout(function() {

                    cellSize = computeCellSize();

                    resizeCanvas();

                    createGrid();

                    randomize();

                    draw();

                }, 150);

            });


            init();

        })();

    </script>
